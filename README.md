# BodyTrack · demonstração

Versão de demonstração do BodyTrack, acompanhamento de composição corporal e nutrição esportiva.

Abra em <https://eduranti.github.io/bodytrack-demo/> e use **“Carregar pacientes de demonstração”**: dois atletas e uma paciente geral, todos **fictícios**.

Não registre dados de paciente real: o endereço é público. O que for registrado fica apenas no navegador de quem abre (IndexedDB) e não é enviado a servidor nenhum.

Gerado a partir do BodyTrack 11.6.1.
